# 한글 카드 자료 덧붙이기

영문 기준으로 만든 `public/cards.json`에 한글 카드 이름·문장·그림을 덧붙인다. 기존 칸(`n` 등)은 바꾸지 않는다.

## 자료 출처

- 한글 카드: 링크 님 PC의 `F:\AI\17_포켓몬 카드\data\kr\cards_kr.json` (pokemoncard.co.kr 공식 카드 검색에서 모은 자료, 20,552장). 이 폴더는 읽기만 한다.
- 한글 그림 비교용: 같은 폴더의 `images\kr\…webp`, 영문 그림 `images\en\small\…png`
- 영문 원본: `card-src/cards_en.json` (`tools/fetch-cards.py`로 받은 것. 작가·레어도 정보를 씀)

## 만드는 순서

```bash
python tools/build-cards.py card-src/cards_en.json card-src/sets_en.json public/cards.json
node tools/kr-art-hash.cjs "F:\AI\17_포켓몬 카드" public/cards.json card-src/art_hash.json
python tools/build-cards-kr.py "F:\AI\17_포켓몬 카드\data\kr\cards_kr.json" --en card-src/cards_en.json --hash card-src/art_hash.json
```

`kr-art-hash.cjs`는 wrangler와 함께 설치되는 `sharp`를 쓴다. 지문은 `card-src/art_hash.json`에 저장되고, 다시 돌리면 새 카드만 계산한다.

## 짝짓는 방법 (세트 번호가 아니라 카드 자체로)

- **포켓몬**: 한글 종 이름 + HP + 기술(비용·데미지) + 약점 + 후퇴가 모두 같은 한글 카드. 같은 카드가 여러 판(일반·AR·SAR 등)이면 그림 지문이 가장 닮은 판을 고른다 (그다음 작가, 레어도).
- **트레이너스·특수 에너지**: 같은 종류(서포트/아이템/도구/스타디움/특수 에너지)이고 레귤레이션이 같은 한글 카드 중 일러스트 부분 그림 지문(dHash 256비트)이 가장 닮은 것. 1등이 70비트 이하로 다르고, 이름이 다른 2등보다 12비트 이상 가까울 때만 표를 준다. 판마다 받은 표를 모아 영문 이름 → 한글 이름 번역을 정한다 (248개).
- **기본 에너지**: 타입 이름으로 (`Basic Fire Energy` → `기본 불꽃 에너지`).
- 한글 자료의 가짜 기술 칸(`ex 룰`, `메가진화 ex 룰`, `테라스탈`)은 기술에서 빼고 `kr`(규칙 문장)로 옮긴다.

## 덧붙이는 칸

| 칸 | 뜻 |
| --- | --- |
| `kn` | 카드에 인쇄된 한글 이름 (예: `피카츄 ex`, `보스의 지령`) |
| `kimg` | 한글 카드 그림 (공식 사이트 주소 `https://pokemoncard.co.kr/…webp`, 가로 868px) |
| `kab` / `kat` | `ab` / `at`과 같은 순서의 한글 특성·기술 `{n, t}` |
| `kr` | 한글 규칙 문장 (ex 룰, 테라스탈, 트레이너스 효과 문장 등) |
| `kset` / `kno` | 한글판 세트 코드와 번호 |

## 결과 (2026-11-17)

- 영문 표준 카드(H·I·J + 기본 에너지) **3,182장 중 3,129장(98.3%)** 에 한글 자료를 붙였다.
  - 포켓몬 2,633 / 2,671, 트레이너스 456 / 469, 에너지 40 / 42
  - 고른 한글판 그림이 영문판과 다른 그림인 경우 33장 (같은 카드지만 해당 그림의 한글판이 자료에 없을 때)
- 한글 표준 카드 4,826장(이름 1,459개) 중 영문 쪽에 짝이 없는 이름 28개 (예: 가이오가ex, 다크라이ex, 자시안ex, 희망의 애뮬렛, 기본 페어리 에너지 등). 영문 자료에 아직 없는 최신 카드거나 구판 재록이라, 새 카드로 넣지는 않았다.
- 짝을 못 찾은 영문 카드 53장: 같은 이름의 포켓몬이 여러 장이라 수치가 겹치는 경우(이브이, 마릴, 데기라스 등)와 부스트 에너지 캡슐·레전드 계열 등. `-v`로 목록을 볼 수 있다.
