# 한글 카드 자료 덧붙이기

영문 기준으로 만든 `public/cards.json`에 한글 카드 이름·문장·그림을 덧붙인다. 기존 칸(`n` 등)은 바꾸지 않는다.
영문 자료에 없는 한국판 카드(한국·아시아 전용 카드, 영문과 다른 30th CELEBRATION 카드 등)는 한글 자료로 새 대전 카드를 만들어 뒤에 붙인다.

## 자료 출처

- 한글 카드: 링크 님 PC의 `F:\AI\17_포켓몬 카드\data\kr\cards_kr.json` (pokemoncard.co.kr 공식 카드 검색에서 모은 자료, 20,552장). 이 폴더는 읽기만 한다.
- 한글 그림 비교용: 같은 폴더의 `images\kr\…webp`, 영문 그림 `images\en\small\…png`
- 영문 원본: `card-src/cards_en.json` (`tools/fetch-cards.py`로 받은 것. 작가·레어도 정보를 씀)

## 만드는 순서

```bash
python tools/build-cards.py card-src/cards_en.json card-src/sets_en.json public/cards.json
node tools/kr-art-hash.cjs "F:\AI\17_포켓몬 카드" public/cards.json card-src/art_hash.json
python tools/build-cards-kr.py "F:\AI\17_포켓몬 카드\data\kr\cards_kr.json" --en card-src/cards_en.json --hash card-src/art_hash.json --match card-src/kr_match.json -v
```

- `--match` (선택): 자동으로 못 맞춘 카드를 손으로 정한 표. `{"영문 id": "한글 code"}` 꼴이고 `_`로 시작하는 키는 메모로 본다. 트레이너스는 한 판만 적어도 같은 영문 이름의 다른 판이 모두 그 한글 카드를 쓴다. 한글 code는 레귤레이션과 상관없이 찾으므로 한글판이 G 마크뿐인 카드(부스트 에너지 고대 등)도 짝지을 수 있다.
  - `"fix:<한글 code>": {"hp": 70}`처럼 적으면 한글 원본에 빠진 칸을 채운 뒤 짝짓는다.
- 다시 돌려도 된다. 지난번에 넣은 한국판 카드(`kro`)는 지우고 새로 만든다.
- 카드 자료를 바꾼 뒤에는 `wrangler dev`를 껐다 켜야 서버의 덱 검사도 새 카드를 안다.

`kr-art-hash.cjs`는 wrangler와 함께 설치되는 `sharp`를 쓴다. 지문은 `card-src/art_hash.json`에 저장되고, 다시 돌리면 새 카드만 계산한다.

## 짝짓는 방법 (세트 번호가 아니라 카드 자체로)

- **포켓몬**: 한글 종 이름 + HP + 기술(비용·데미지) + 약점 + 후퇴가 모두 같은 한글 카드.
  - 이름: 영문이 `Team Rocket's`·`Misty's`·`Iono's`처럼 주인 이름이 붙은 카드는 `로켓단의 ○○`·`이슬의 ○○`처럼 `…의`가 붙은 한글 카드와만, 주인 이름이 없는 카드는 `…의`가 없는 한글 카드와만 짝짓는다.
  - 비용 없는 기술: 영문 `Free`와 한글 빈 비용을 같게 본다.
  - 영문 원본에 데미지가 빠진 기술(예: Seaking의 `30×`)은 그 칸만 너그럽게 본다. 같은 카드가 여러 판이면 일반 판(C·U·R·RR·프로모)을 먼저, 그다음 AR, 마지막에 SR·SAR·UR 같은 특별 판을 쓴다. 같은 등급 안에서는 그림 지문·작가가 닮은 판, 그다음 낮은 번호.
- **트레이너스·특수 에너지**: 같은 종류(서포트/아이템·도구/스타디움/특수 에너지. 한글 자료에 아이템과 도구가 섞여 적힌 카드가 있어 둘은 한 묶음)이고 레귤레이션이 같은 한글 카드 중 일러스트 부분 그림 지문(dHash 256비트)이 가장 닮은 것. 1등이 70비트 이하로 다르고, 이름이 다른 2등보다 12비트 이상 가까울 때만 표를 준다. 판마다 받은 표를 모아 영문 이름 → 한글 이름 번역을 정한다 (248개). 이 기준으로 표가 하나도 없는 이름만 80비트·15비트 차이로 한 번 더 본다.
- **기본 에너지**: 타입 이름으로 (`Basic Fire Energy` → `기본 불꽃 에너지`). 옛 DP의 `기본 강철 에너지`처럼 이름만 기본이고 종류가 특수 에너지인 카드는 뺀다.

## 한국판 카드 (영문에 없는 카드)

한글 H·I·J 카드(+기본 에너지)를 같은 카드끼리(포켓몬은 이름·HP·기술·약점·후퇴, 트레이너스는 종류·이름) 묶고, 영문 카드와 하나도 이어지지 않은 묶음은 일반 판 하나를 골라 새 카드로 넣는다.

| 칸 | 값 |
| --- | --- |
| `id` | `kr-<한글 code>` (예: `kr-BS2024002012`) |
| `kro` | `1` (한국판 카드 표시. 화면에 "한국판 카드"로 나오고, PTCGL 덱 리스트의 세트 번호 찾기에서는 뺀다) |
| `n`, `kn` | 한글 이름 (기본 에너지만 `n`이 `Basic Fairy Energy`처럼 영문: 판에서 에너지 타입을 이 이름으로 읽음) |
| `sub` | 진화 단계(`Basic`/`Stage 1`/`Stage 2`), `MEGA`, `Tera`, `ex`, `Ancient`/`Future`, 트레이너스 종류, `ACE SPEC` |
| `hp`, `ty`, `at`, `ab`, `wk`, `rs`, `rt` | 한글 자료 그대로 (타입은 영문 이름으로, 기술 이름·문장은 한글) |
| `r`, `kr` | 규칙 문장 |
| `set`, `no`, `rm`, `kimg`, `kset`, `kno` | 한글판 세트·번호·레귤레이션·그림 |

덱의 "같은 이름 4장" 검사는 한글 이름이 있으면 한글 이름으로 센다. 그래서 영문 카드와 한국판 카드가 섞여도 같이 센다.
- 한글 자료의 가짜 기술 칸(`ex 룰`, `메가진화 ex 룰`, `테라스탈`)은 기술에서 빼고 `kr`(규칙 문장)로 옮긴다.

## 덧붙이는 칸

| 칸 | 뜻 |
| --- | --- |
| `kn` | 카드에 인쇄된 한글 이름 (예: `피카츄 ex`, `보스의 지령`) |
| `kimg` | 한글 카드 그림 (공식 사이트 주소 `https://pokemoncard.co.kr/…webp`, 가로 868px) |
| `kab` / `kat` | `ab` / `at`과 같은 순서의 한글 특성·기술 `{n, t}` |
| `kr` | 한글 규칙 문장 (ex 룰, 테라스탈, 트레이너스 효과 문장 등) |
| `kset` / `kno` | 한글판 세트 코드와 번호 |

## 결과 (2026-11-17)

- 영문 표준 카드(H·I·J + 기본 에너지) **3,182장 중 3,158장(99.2%)** 에 한글 자료를 붙였다.
  - 포켓몬 2,647 / 2,671, 트레이너스 469 / 469, 에너지 42 / 42 (자동 3,144장, 손으로 정한 짝 14장)
  - 남은 24장은 모두 영문 30th Celebration(me55) 카드로, 한글판 30th CELEBRATION(M6a)과 기술이 다른 카드라 짝이 없다.
  - 일반 판 우선으로 바꾸면서 1,197장의 그림이 바뀌었다. 그래서 영문판(특별 그림)과 한글판 그림이 다른 카드가 860장이다.
- 한글 표준 카드 4,825장(같은 카드끼리 묶어 2,128종)은 **모두 대전에서 쓸 수 있다**: 2,082종은 영문 카드와 이어졌고, 46종(포켓몬 41, 트레이너스 4, 에너지 1)은 한국판 카드(`kro`)로 새로 넣었다. 예: 다크라이 ex(SVI 034), 가이오가 ex, 자시안 ex, 피크닉걸, 축하 팡파레, 기본 페어리 에너지.
- 손으로 정한 짝(`card-src/kr_match.json`, PC에만 있음): 희망의 애뮬렛, 청목의 노고고치 ex, 부스트에너지 고대·미래, 제트 에너지, 루미너스 에너지, 레포르, 스코빌런 ex(풀), 전설의 용암동굴·산정·해구(영문은 반쪽 2장씩). 한글 원본에 HP가 빠진 곤율거니(SV-P 081)는 그림에서 읽은 HP 120으로 채웠다.
- 한글 원본에서 그림이 없는 카드는 SV11B 109 한 장(공식 사이트에서 열리지 않음).
